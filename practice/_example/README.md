# Example folder

This shows the structure. **Copy it under your own name** — e.g. make
`practice/liran/` — and work there. Don't edit files in `_example/`.

```
practice/<your-name>/
  learn/
    00/  01/ … 09/
  p01/
  se01/
```

- One folder per lesson under `learn/`.
- One `.java` file per exercise is fine, or group a few in one file.
- Every file needs a `public class` whose name matches the file name.
